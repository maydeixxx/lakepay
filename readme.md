# Биржа игровых аккаунтов LakePay

Веб-приложение "Биржа аккаунтов" предоставляет пользователям платформу для создания, просмотра и покупки объявлений об аккаунтах с акцентом на безопасность транзакций и удобство использования.

## Функциональность:

- 📝 Создание объявления на покупку своего аккаунта 
- 📊 Проверить статус своих объявлений
- 🪙 Совершить покупку игрового аккаунта
- ✉️ Возможность общаться в чате с продавцом или покупателем
- 🤖 Телеграм-бот для отслеживания избранных категорий

## Технический стек

- **Frontend**: React JS для динамического интерфейса, Tailwind CSS  для стилизации.
- **Backend**: Java Spring с микросервисной onion-архитектурой.
- **Дизайн**: Figma.
- **База данных**: PostgreSQL.
- **Инструменты**: Git, Docker.


## Установка и запуск

Веб-сайт доступен на домене https://www.lakepay.ru
